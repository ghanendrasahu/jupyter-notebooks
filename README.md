# Jupyter Notebooks

A collection of machine learning and data science notebooks — from fundamentals through classical ML to deep learning and GenAI.

## Contents

- **Data Fundamentals** - preprocessing, plotting, probability, statistics
- **Regression** - multiple linear regression, housing price projects
- **Classification** - iris, KNN, SVM (linear & kernel), fruit classification
- **Clustering & Stats** - centroids, synthetic datasets, histograms
- **NLP** - spam classification with NLTK and scikit-learn
- **Course Projects** - final project and personal ML projects
- **Deep Learning Survey** - end-to-end notebook covering logistic regression through CNN, RNN/LSTM, and transfer learning
- **PyTorch** - deep learning introduction
- **GenAI** - agentic AI concepts

## Learning Path

Notebooks progress from data fundamentals → regression → classification → clustering → NLP → applied projects → deep learning → GenAI.
